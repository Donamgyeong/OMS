# 월별 근무 집계·Excel 다운로드

상단 **월별 근무 집계**에서 시작·종료 월(최대 12개월), 부서·사용자를 선택한 뒤 조회하거나 Excel을 다운로드한다. 퇴사·비활성 사용자도 해당 기간에 기록이 있으면 포함된다. 화면은 100행씩 표시하고 Excel은 조회 범위 전체를 제공한다.

## 계산

- 사전등록 계획: 근무 시작 전 제출한 무승인 확정·승인 완료·승인 대기. 상태별로 나눈다.
- 사전 확정 계획: 위에서 승인 대기를 제외한 합계다. 계획을 여러 실적에 연결해도 한 번만 집계한다.
- 사후등록 계획은 별도로 표시하며, 임시 저장·반려·취소는 합계에서 제외하고 상세에만 남긴다.
- 실제 총 근무·실제 초과 근무는 저장된 일별 계산값을 사용한다. 현재 휴일·근무 기준으로 재계산하지 않는다.
- 포함 기준 초과분은 `max(사용자별 월 실제 초과 근무 - 월 포함 기준, 0)`이다. 기본 기준은 960분(16시간)이며 월간 잔여 시간은 이월하지 않는다.
- 포함 기준은 **기초정보 → 보고용 월 포함 기준**에서 적용 시작 월의 1일과 분 단위로 관리한다. 기존 승인 기준과 별개다. 최초 마이그레이션은 1900-01부터 960분을 등록한다.
- 과거 기준을 편집하거나 실적을 수정하면 재조회 결과도 달라진다. 급여액 산정이나 마감 확정 자료를 생성하는 기능은 아니다.

## 부분·불완전 자료

일반 사용자는 본인, 부서장은 본인 및 소속 부서에 저장된 기록, 관리자는 전체를 조회한다. 특정 계획의 지정 결재자라는 이유로 그 사용자의 전체 월 기록을 볼 수 없다.

부서 이동·부서 필터·권한 때문에 월 기록 일부만 조회되면 시간은 조회 범위 내 합계만 제공하고 월 전체 초과분은 빈칸/확인 필요로 표시한다. 숨겨진 기록의 시간과 부서는 노출하지 않는다. 요약 카드의 초과분 합계는 확인 가능한 월만 더한 값이다.

일별 내역이 없는 과거 단일 월 실적은 저장 총량을 사용하며 확인 사항을 표시한다. 월을 넘는 자료 또는 일별 합계가 저장 총량과 일치하지 않는 자료는 임의로 배분하지 않는다. 관련 월은 초과분을 미확정으로 표시하고, 상세·검토 시트에서 실적 ID로 확인할 수 있다. 이 경우 실제 시간 합계는 정상적으로 월 배분된 기록만 포함한다.

## Excel 및 운영

4개 시트는 월별 사용자 요약, 계획 상세, 실적 상세, 집계 기준·검토 사항이다. 요약의 시간 항목은 숫자 분과 시간·분 문자열을 함께 제공한다. 실적 상세의 휴게시간은 원본 실적 전체의 값이므로 같은 실적의 여러 일자 행에서 반복 합산하지 않는다.

사용자 입력은 문자열로 저장해 수식 실행을 방지한다. Excel에서 지원하지 않는 제어문자는 제거하고 셀당 텍스트는 32,767자로 제한한다. 파일은 인증 후 즉시 생성하며 공유 캐시를 막는다. 다운로드 수행자·시각·조회 조건·요약 행 수는 감사 이력으로 남기고 최고관리자가 Django 관리자 화면에서 조회할 수 있다.

조회는 원본 계획·실적 합계 10,000건, 상세 50,000행으로 제한한다. 한도를 넘으면 기간·부서·사용자를 좁히도록 안내한다. PostgreSQL에서는 집계 읽기를 REPEATABLE READ 트랜잭션으로 묶어 모든 시트에 같은 자료를 사용한다.

배포 시 업데이트한 `requirements.txt`와 `requirements.lock`으로 이미지를 빌드하고 `python manage.py migrate`를 적용한다. 기존 NAS 배포 스크립트가 두 단계를 처리한다. 외부 API 권한이나 별도 워커는 필요하지 않다.
