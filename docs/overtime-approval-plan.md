# 초과 근무 계획 사전 승인 시스템 기획

- 작성일: 2026-10-23
- 상태: 초기 기획안. 권장 기본안은 운영 정책 확정 시 조정한다.

## 1. 목적과 기본 기준

초과 근무 계획을 사전에 등록하고, 승인 여부와 실제 근무 내역을 함께 관리한다. 계획과 실적은 분리한다.

회사는 연봉에 월 16시간까지 초과 근무를 포함하는 포괄 임금제를 운영하고 있으며, 시스템은 사용자가 제시한 이 운영 기준을 반영한다.

| 항목 | 기준 |
|---|---|
| 관리 단위 | 사용자별·월별 |
| 무승인 범위 | 월 누적 초과 근무 계획 16시간 이하 |
| 승인 대상 | 신규 계획을 포함한 월 누적 계획이 16시간을 초과하는 경우 |
| 승인자 | 소속 부서장 |
| 계획 | 앞으로 수행할 초과 근무의 시간·업무·사유 |
| 실적 | 실제 근무 시간과 업무 내역 |
| 입력 방식 | 초기 수동 입력, 향후 외부 근태 API 연동 |
| 시간 저장 | 분 단위 저장, 화면에는 시간·분 표시 |

무승인은 기록 면제가 아니라 계획 제출 후 별도 결재 없이 확정되는 것을 의미한다. 월 16시간 기준은 코드에 고정하지 않고 정책으로 설정한다.

## 2. 역할과 권한

| 기능 | 일반 사용자 | 부서장 | 관리자 |
|---|---|---|---|
| 본인 계획 등록·기안 | 가능 | 가능 | 가능 |
| 본인 근무 시간 등록 | 가능 | 가능 | 가능 |
| 근무·초과 근무 조회 | 본인 | 본인 및 소속 부서 | 전체 구성원 |
| 승인·반려 | 불가 | 소속 부서 | 별도 승인 권한이 있을 때 |
| 부서 관리 | 불가 | 조회 | 가능 |
| 사용자·역할 관리 | 불가 | 소속 부서 조회 | 가능 |
| 운영 정책 설정 | 불가 | 불가 | 가능 |
| 이력 조회 | 본인 관련 처리 | 부서 관련 처리 | 전체 |

관리자의 열람 권한과 승인 권한은 분리한다. 부서장도 본인 계획을 등록할 때는 일반 사용자 기능을 사용한다. 화면뿐 아니라 서버에서 조회·수정 범위를 검증하며 다운로드에도 같은 권한을 적용한다.

## 3. 월 누적 시간과 승인 판단

월 누적 계획 시간 = 무승인 확정 시간 + 승인 완료 시간 + 승인 대기 시간.

임시 저장·반려·취소 건은 제외한다. 여러 신청을 나누어 제출하는 경우에도 기준이 적용되도록 승인 대기 시간을 포함한다.

| 기존 누적 | 신규 계획 | 제출 후 누적 | 결과 |
|---|---|---|---|
| 10시간 | 4시간 | 14시간 | 무승인 확정 |
| 14시간 | 2시간 | 16시간 | 무승인 확정 |
| 15시간 | 3시간 | 18시간 | 부서장 승인 대기 |
| 18시간 | 1시간 | 19시간 | 부서장 승인 대기 |

권장 기본안은 기준을 넘기는 신규 계획 전체를 승인 대상으로 처리하는 것이다. 15시간에서 3시간을 추가하면 초과분 2시간만이 아니라 신규 3시간 전체를 승인받는다.

- 동시 제출에도 누적 계산과 상태 결정이 일관되어야 한다.
- 수정 시 기존 계획 시간을 빼고 변경 시간을 반영한다.
- 월 경계를 넘는 계획은 월별로 시간을 나눈다.
- 반려·취소 후 다른 승인 대기 건을 자동 확정하지 않고 기존 상태를 유지한다.
- 제출 당시 누적 시간, 적용 정책, 승인 필요 여부를 보존한다.

## 4. 초과 근무 등록 및 기안

| 항목 | 내용 |
|---|---|
| 신청자·소속 | 로그인 정보로 자동 입력 |
| 예정일 | 초과 근무 수행 날짜 |
| 시작·종료 시각 | 예정 시간 |
| 휴게 시간 | 초과 근무 시간에서 제외 |
| 초과 근무 시간 | 자동 계산 |
| 업무명 | 수행할 업무 |
| 상세 내용·필요 사유 | 초과 근무가 필요한 이유 |
| 프로젝트·첨부파일 | 선택 입력 |
| 승인자 | 소속 부서 기준 자동 지정 |

화면에는 월 무승인 기준, 현재 누적 계획, 이번 신청 시간, 제출 후 누적, 남은 무승인 시간, 승인 필요 여부와 승인자를 표시한다.

임시 저장과 제출을 지원한다. 제출 시 기준 이내이면 무승인 확정, 초과하면 승인 대기로 처리한다.

## 5. 부서장 승인

승인자는 신청 일시·시간·업무·사유, 월 누적 계획의 상태별 시간, 월 실제 초과 근무 시간, 같은 달의 다른 계획, 수정 전후 내역을 확인한다.

- 승인 및 승인 의견 입력
- 반려 및 반려 사유 입력
- 신청자에게 결과 알림
- 승인자·처리 시각·의견 기록
- 이미 처리된 건의 중복 처리 방지

부서장 본인의 신청은 상위 책임자 또는 지정 승인자가 처리한다. 자기 승인은 허용하지 않는다.

## 6. 상태와 변경 처리

결재 상태와 실적 등록 상태는 별도로 관리한다.

| 계획 상태 | 의미 |
|---|---|
| 임시 저장 | 작성 중, 누적 미반영 |
| 무승인 확정 | 기준 이내 제출 완료 |
| 승인 대기 | 부서장 결재 필요 |
| 승인 완료 | 승인 처리 완료 |
| 반려 | 수정·재기안 가능 |
| 취소 | 실행하지 않는 계획 |

- 승인 대기는 회수 후 수정·재제출한다.
- 확정 계획의 시간·날짜·업무 범위를 바꾸면 승인 필요 여부를 다시 계산한다.
- 승인된 계획 변경 시 기존 승인 내용과 변경 내용을 보존하고 필요한 경우 재승인받는다.
- 근무 시작 후 등록은 사후 등록으로 구분한다.
- 실적이 연결된 계획은 삭제하지 않고 변경·취소 이력을 남긴다.

## 7. 근무 시간과 실적 등록

일반 근무를 포함한 실제 근무 시간을 등록하고 초과 근무 계획과 연결한다.

| 항목 | 내용 |
|---|---|
| 근무일 | 실제 근무 날짜 |
| 출근·퇴근 시각 | 실제 시작·종료 |
| 휴게 시간 | 실제 근무에서 제외 |
| 실제 근무 시간 | 자동 계산 |
| 실제 초과 근무 시간 | 회사 근무 기준으로 산정 |
| 연결 계획 | 관련 사전 계획 |
| 업무 내용 | 실제 수행 업무 |
| 등록 출처 | 수동 또는 외부 API |
| 수정 사유 | 기존 기록 변경 시 입력 |

사용자별 소정근무 일정과 휴일을 관리한다. 유연근무·교대근무가 있다면 근무 유형을 추가한다.

| 상황 | 처리 |
|---|---|
| 계획 3시간, 실적 2시간 | 실적 2시간과 차이 표시 |
| 계획 2시간, 실적 4시간 | 초과 수행 2시간 표시, 사유 입력 |
| 계획 없는 초과 근무 | 미계획 실적 표시, 사유 입력 |
| 승인 대기 상태에서 근무 | 사전 승인 미완료 표시 |

승인 여부와 관계없이 실제 근무 기록을 남길 수 있어야 한다. 계획·승인 기준을 벗어난 실적은 별도로 확인한다.

## 8. 조회와 대시보드

| 화면 | 주요 내용 |
|---|---|
| 개인 대시보드 | 월 계획·실적, 남은 무승인 시간, 승인 대기 |
| 개인 근무 내역 | 일별 근무, 초과 근무 계획·실적 |
| 부서 대시보드 | 부서원별 계획·실적, 결재 대기, 계획 대비 차이 |
| 관리자 대시보드 | 전체·부서별 현황, 미계획·미승인 실적 |
| 결재함 | 승인 대기·완료·반려 내역 |

기간, 부서, 사용자, 승인 상태, 실적 등록 여부로 검색한다. 월별로 총 실제 근무, 실제 초과 근무, 무승인 확정 계획, 승인 완료 계획, 승인 대기 계획, 계획 대비 차이, 미계획 초과 근무를 구분한다. 엑셀 다운로드를 지원한다.

## 9. 관리자 페이지와 사용자 등록

| 영역 | 기능 |
|---|---|
| 부서 | 등록·수정·비활성화, 상위 부서, 부서장 |
| 사용자 | 등록, 사번, 소속, 역할, 재직 상태 |
| 가입 | 초대 또는 가입 신청, 관리자 승인, 활성화 |
| 승인자 | 부서별 승인자, 기간별 대결자, 본인 신청 승인자 |
| 근무 기준 | 일정, 휴게, 휴일, 사용자별 근무 유형 |
| 초과 근무 정책 | 월 기준 시간, 적용 시작일, 등록·변경 기준 |
| 이력 | 권한 변경, 계획 변경, 결재, 근무 기록 수정 |

초기에는 관리자 등록 또는 초대를 권장한다. 직접 가입을 지원하면 관리자 승인 후 이용하도록 한다. 사용자는 관리자·부서장 역할을 직접 선택할 수 없다.

부서 이동과 부서장 변경에는 적용일을 두고 과거 소속·결재 이력을 보존한다.

시스템 내 알림을 우선 구현하고 이메일·사내 메신저는 이후 확장한다.

## 12. 개발 단계

| 단계 | 범위 | 완료 기준 |
|---|---|---|
| 1. 정책·설계 | 계산, 승인, 역할, 예외, 화면 | 대표 시나리오 확정 |
| 2. 핵심 기능 | 로그인, 사용자·부서, 계획, 누적 계산, 결재, 수동 실적, 권한별 조회 | 신청부터 실적 조회까지 운영 가능 |

첫 출시 범위는 사용자·부서 관리, 계획 등록·기안, 부서장 승인, 수동 실적 등록, 권한별 조회로 한다.

## 13. 출시 전 검증

- 정확히 16시간이면 무승인 확정된다.
- 16시간을 초과하면 승인 대기로 전환된다.
- 동시 제출로 승인 기준을 우회할 수 없다.
- 수정·취소·반려 시 누적 시간이 정확하다.
- 개인·부서장이 권한 밖 기록에 접근할 수 없다.
- 계획과 실적의 차이를 확인할 수 있다.
- 월 경계, 부서 이동, 승인자 변경 후에도 과거 기록이 유지된다.
