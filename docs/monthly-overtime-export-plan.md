# 월별 사용자 근무 집계·다운로드 구현 계획

작성일: 2026-11-03. 계획 단계이며 실행 코드는 변경하지 않는다.

## 1. 목표

선택한 기간에 대해 사용자별·월별 사전등록 초과 근무 계획, 실제 근무, 실제 초과 근무 및 연봉 포함 16시간을 넘는 실제 초과 근무를 화면에서 확인하고 Excel 파일로 다운로드한다.

기본 집계 단위는 `사용자 ID + 근무 귀속 월`이다. 사번·이름이 변경되거나 같은 달에 부서 이동이 있어도 동일 사용자의 월 기준을 중복 차감하지 않는다. 시간은 내부적으로 분 단위로 계산한다.

## 2. 계산 기준

| 항목 | 계산·포함 기준 |
|---|---|
| 사전등록 계획 | 근무 시작 전에 제출한 무승인 확정·승인 완료·승인 대기 계획. 세 상태를 각각 표시 |
| 사전 확정 계획 | 위 사전등록 계획 중 무승인 확정 + 승인 완료. 승인 대기는 제외 |
| 사후등록 계획 | 근무 시작 이후 제출한 계획. 사전등록과 분리 |
| 제외 계획 | 임시 저장·반려·취소. 상세에는 상태를 표시할 수 있으나 합계에서 제외 |
| 실제 총 근무 | 저장된 일별 `worked` 합계. 휴게시간은 이미 제외되어 있으므로 다시 차감하지 않음 |
| 실제 초과 근무 | 저장된 일별 `overtime` 합계. 계획·승인 유무와 관계없이 실제 등록 시간을 집계 |
| 연봉 포함 기준 | 사용자별·월별 기본 960분(16시간) |
| 포함 기준 내 실제 초과 근무 | `min(실제 초과 근무, 960분)` |
| 포함 기준을 넘는 실제 초과 근무 | `max(실제 초과 근무 - 960분, 0)` |
| 계획 대비 차이 | 실제 초과 근무 − 사전 확정 계획. 음수도 유지 |

예: 실제 총 근무가 190시간이고 실제 초과 근무가 23시간 30분이면, 16시간 초과분은 **7시간 30분**이다. 총 근무 190시간에서 16시간을 빼지 않는다.

16시간은 초과 근무 승인 판단에 사용하는 `OvertimePolicy.threshold_minutes`와 구분한다. 승인 기준 변경이 과거의 연봉 포함 기준을 바꾸면 안 된다. 월 적용 시작일과 포함 시간(기본 960분)을 갖는 별도 보고 기준을 추가하고, 월 중간 변경은 허용하지 않는다. 사용자별 예외 기준과 급여 금액 계산은 최초 범위에서 제외한다.

여러 달을 조회할 때 총 초과분은 **각 월의 초과분을 먼저 계산한 뒤 합산**한다. 예를 들어 1월 10시간, 2월 22시간이면 총 초과분은 6시간이며, 월 사이에 남은 포함 시간을 이월하지 않는다.

## 3. 월 귀속·자료 품질

- 계획은 기존 `monthly_minutes()`로 월 경계에 따라 나눈다. 휴게는 기존 규칙대로 근무 구간 끝에서 차감한다.
- 실적은 서울 시간 기준 저장된 `daily_minutes`를 월별로 합산한다. 야간·월말·연말 근무도 실제 날짜에 귀속한다.
- 과거 보고 시 현재 휴일이나 현재 근무 기준으로 실적을 재계산하지 않는다. 저장 당시 계산값을 사용한다.
- `daily_minutes`가 없는 과거 실적은 정상 자료와 구분한다. 단일 월 자료는 저장된 총량을 해당 월에 귀속할 수 있으나, 월을 넘는 자료는 임의 배분하지 않고 검토 대상으로 표시한다. 미배분 실적이 있는 월은 초과분을 확정값으로 표시하지 않는다.
- 계획의 사전·사후 여부는 현재 버전의 제출 시각과 시작 시각을 비교한다. 승인 완료 여부와는 별개다. 상세에 `is_retrospective` 및 시각 불일치도 검토 항목으로 제공한다.
- 현재 저장 상태를 추출 시점 기준으로 보고한다. 과거 특정 마감 시점 재현 및 월 마감·확정 스냅샷은 후속 범위다. 수정 후 재다운로드하면 결과가 달라질 수 있음을 명시한다.
- 미계획 실적, 계획 초과, 등록 당시 사전 승인 미완료, 계획만 있고 연결 실적이 없는 건을 검토 항목으로 표시한다. 계획을 여러 실적에 연결해도 계획 합계를 중복 집계하지 않는다.

## 4. 화면과 접근 범위

근무 현황에 **월별 근무 집계** 메뉴를 추가한다. 기본은 이번 달이며 시작 월·종료 월(최대 12개월), 부서, 사용자를 선택한다. 미리보기와 다운로드는 같은 집계 서비스를 사용한다.

| 역할 | 조회·다운로드 범위 |
|---|---|
| 일반 사용자 | 본인 |
| 부서장 | 본인 및 기존 부서별 열람 권한 범위 |
| 관리자·최고관리자 | 전체 |

현재 `visible_to()`와 기록에 저장된 부서 기준을 사용한다. 외부 지정 결재자에게 특정 계획을 볼 수 있다는 이유로 해당 사용자의 월 전체 보고서를 제공하지 않는다. 퇴사·비활성 사용자도 기간 내 기록이 있으면 포함한다. 기간 내 계획·실적이 전혀 없는 사용자는 기본적으로 제외한다.

부서 이동이나 부서 필터 때문에 한 사용자의 월 기록 일부만 포함될 수 있다. 이 경우 열람 가능한 시간만 표시하고 **사용자 전체 월의 16시간 초과분은 빈칸과 ‘월 전체 확인 필요’로 표시**한다. 일부 기록만으로 전체 월 초과분을 단정하거나, 권한 밖 시간을 역산할 수 있는 전체 합계를 제공하지 않는다. 부분 여부 판단은 서버에서 수행하고 외부 부서명·시간 등 상세는 노출하지 않는다. 관리자도 부서 필터로 일부 기록만 선택했다면 같은 원칙을 적용한다.

사용자 합계에 현재 소속 부서와 기록에 저장된 부서 목록을 구분해 표시한다. 부서별 보조 합계를 추가하더라도 개인의 월 16시간을 부서마다 중복 차감하지 않는다.

## 5. 다운로드 형식

기본은 `.xlsx`이며 파일명은 `OMS_월별근무집계_2026-01_2026-12.xlsx` 형식으로 한다.

| 시트 | 내용 |
|---|---|
| 월별 사용자 요약 | 월, 사번, 이름, 현재 부서, 기록 부서, 사전등록 계획의 상태별 합계, 사전 확정 계획, 사후등록 계획, 실제 총 근무, 실제 초과 근무, 포함 기준, 기준 내 시간, 16시간 초과분, 계획 대비 차이, 검토 여부 |
| 계획 상세 | 계획 ID·버전, 사용자, 기록 부서, 해당 월 배분 시간, 근무 구간, 제출 시각, 사전·사후 구분, 상태, 결재자 |
| 실적 상세 | 실적 ID·버전, 사용자, 기록 부서, 일자별 실제·소정·초과 근무, 휴게, 연결 계획 ID, 예외 사유, 승인 미완료 여부 |
| 집계 기준·검토 사항 | 추출 시각, 조회 조건·열람 범위, 적용 포함 기준, 계산식, 집계 제외·미배분 자료, 부분 집계 안내 |

모든 시간 항목은 합산 가능한 **분 숫자**와 읽기 쉬운 **시간·분 표시**를 제공한다. 24시간을 넘는 누계가 시각처럼 되돌아가지 않도록 한다. 필터·고정 헤더·열 너비를 적용하고, 사용자 입력값은 문자열 셀로 기록해 Excel 수식으로 실행되지 않게 한다. 개인정보는 사번·이름 등 보고에 필요한 항목만 포함한다.

다운로드 응답은 인증·권한을 다시 검증하고 공유 캐시를 방지한다. 다운로드 수행자·추출 시각·조회 조건·건수는 감사 이력에 남기되 파일 본문은 로그에 저장하지 않는다.

## 6. 구현 순서

1. 보고용 월 포함 기준 모델과 마이그레이션을 추가한다. 과거 기준도 기본 16시간으로 명시적으로 초기화한다.
2. `core/reporting.py`에 권한 필터, 월 배분, 사용자별 집계, 부분·불완전 자료 판정과 검토 목록을 구현한다. 계획과 실적은 별도로 집계한 뒤 결합해 다중 조인에 의한 중복을 방지한다.
3. 기간·부서·사용자 필터 폼과 월별 집계 화면, 권한을 적용한 다운로드 endpoint를 추가한다.
4. Excel 생성 라이브러리를 의존성·잠금 파일에 추가하고 요약·상세·기준 시트를 생성한다. 기본은 즉시 생성이며 조회 기간·행 수에 상한을 둔다. 상한 초과 시 범위를 줄이도록 안내한다.
5. 검증과 운영 문서를 추가하고 기존 배포 스크립트의 마이그레이션·정적 파일 빌드 경로로 배포한다. 별도 외부 API 권한은 필요하지 않다.

## 7. 완료 기준

- 0시간·정확히 16시간·16시간 1분·24시간 이상 누계를 정확히 표시한다.
- 월·연 경계, 야간, 휴게, 휴일 실적이 기존 저장값과 일치한다.
- 사전·사후 계획, 승인 대기·반려·취소, 미연결 실적과 여러 실적에 연결된 계획을 정확히 구분한다.
- 1월 10시간·2월 22시간의 총 초과분이 6시간이며 월 사이 포함 시간을 상계하지 않는다.
- 부서 이동·부서 필터·퇴사자·권한 밖 사용자 지정에도 시간 누락이나 정보 노출이 없다. 부분·불완전 월은 확정 초과분으로 표시하지 않는다.
- 화면과 파일의 합계가 같고, Excel에서 시간 열을 합산할 수 있다. 한국어·긴 이름·수식 형태 문자열도 안전하게 열 수 있다.
- 포함 기준 변경, 다운로드 중 데이터 수정, 빈 조회 결과와 대량 자료 제한을 검증한다. 파일 생성 중 각 시트는 동일한 읽기 스냅샷을 사용한다.

## 최초 구현 범위

월별·사용자별 화면 집계와 Excel 다운로드, 기본 16시간 초과분, 상세 근거 및 검토 항목까지 구현한다. 급여액 계산, 사용자별 계약 기준 차등 적용, 월 마감 확정 및 예약 이메일 발송은 후속 기능으로 분리한다.
